\section{Reproducibility}\label{app:repro}
% ======================================================================
The repository separates (i) instance parsing and generation (\texttt{solver/src/instance.*},
\texttt{medidrone/vrpio.py}, \texttt{generate.py}, \texttt{istanbul.py}), (ii) solution representation and
evaluation (\texttt{solution.*}, \texttt{routes.hpp}), (iii) Clarke--Wright (\texttt{savings.*}), (iv) GA/MA
(\texttt{split.*}, \texttt{ga.*}, \texttt{localsearch.*}), (v) TS (\texttt{tabu.*}), (vi) the exact solvers and the
independent checker (\texttt{medidrone/exact.py}, \texttt{checker.py}) and (vii) experiment and analysis scripts.
All code is our own; ideas adapted from the literature are cited in the file headers (Split: \citep{prins2004simple,vidal2016split};
OX: \citep{davis1985applying}; granular neighbourhoods: \citep{toth2003granular}; penalty update: \citep{gendreau1994tabu,cordeau2001unified}).
No VRP or metaheuristic library is used; HiGHS (through SciPy) is used only for the tiny ground-truth instances.
\begin{verbatim}
make -C solver                                   # C++17 solver, no dependencies
python3 -m medidrone.generate --ids 2267273      # team + tiny instances (seed 7273)
python3 -m medidrone.istanbul                    # real Istanbul instance (cached OSM data)
python3 experiments/run_all.py                   # every experiment (~2 h on 8 cores)
python3 -m medidrone.checker results/raw --csv results/validation.csv
python3 analysis/make_all.py                     # every figure and table
latexmk -pdf -cd report/main.tex                 # this report
\end{verbatim}
Raw results of all runs are stored as one JSON file per run (\texttt{results/raw/}) and as CSV
(\texttt{results/all\_runs.csv}).
